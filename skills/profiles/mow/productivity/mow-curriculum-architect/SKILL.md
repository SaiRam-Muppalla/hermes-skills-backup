# Makers on Wheels: Curriculum Architect

Use this skill to design practical, hands-on workshops, bootcamps, and code labs for students.

## Pedagogy Standards (80/20 Rule)
- 80% hands-on coding, terminal exercises, and building.
- 20% architectural mental models (zero generic PowerPoint slop).

## Deliverable Pack Structure
For any workshop topic:
1. **Day-by-Day Agenda**: Hourly schedule breakdown with learning milestones.
2. **Prerequisites Guide**: Exact installation commands (Python, Git, VS Code, Node.js).
3. **Hands-on Labs**: Step-by-step tutorial markdown with copy-pasteable code and verification tests.
4. **Capstone Project Brief**: Problem statement, starter GitHub boilerplate, and evaluation rubric.
5. Save the finished courseware pack into Obsidian Vault under `Curricula & Labs/`.
