# Platform and method selection

| Phone | Recommended method | Computer-side action | Phone-side action |
|---|---|---|---|
| Android, free/local-first | Syncthing + Syncthing-Fork | Install Syncthing, add the vault, show the computer device ID, pair and share the folder | Add the computer as a remote device, accept/share the folder, choose a local directory, then open it in Obsidian |
| iPhone/iPad | Official Obsidian Sync | Configure Obsidian Sync and sign in to the same account | Install Obsidian, sign in, enable Sync, and select the vault |
| Android or iOS, simplest managed setup | Official Obsidian Sync | Configure Obsidian Sync and sign in | Install Obsidian, sign in, enable Sync, and select the vault |

For Syncthing, verify the local web interface responds before adding the vault. After pairing, verify the folder is shared and synchronized rather than relying only on a successful device connection. For an initial Android transfer, keep both devices on the same Wi-Fi and avoid simultaneous edits until the first sync completes.
